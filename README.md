# DiceKey Vault

Regenerates a few rarely used keys (SSH, WireGuard, age, passphrases and BIP39 wallet phrases) from a [DiceKey](https://dicekeys.com), and stores none of them. Scan or type the 25 dice and the same keys come out every time.

It is not a password manager, which a box of dice could never beat for daily use. A DiceKey is an offline root secret, which suits the few keys that are rarely touched and costly to lose: the app is where those are regenerated, never where they are used.

It reads DiceKeys, made by DiceKeys, LLC, and is not their app. It began as a fork of [dicekeys/dicekeys-app-ios](https://github.com/dicekeys/dicekeys-app-ios).

## Building

Requires the Xcode version named by `xcodeVersion` in `project.yml`. The project is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen), pinned in `BuildTools/` and built on first
use (about a minute):

```
swift run --package-path BuildTools xcodegen generate
swift format format --in-place --recursive DiceKeyVault Packages Tests   # before committing
open DiceKeyVault.xcodeproj
```

Put your Apple Developer team id in `Config/Signing.local.xcconfig`, select the `DiceKeyVault`
scheme and a device, then Product → Run.

Key derivation and the DiceKey scanner are pure Swift, in the local packages
`Packages/Derivation` and `Packages/ReadDiceKey`.

## Testing the app

You need a DiceKey, a box of 25 dice, to scan with the camera. Without one, go to
https://dicekeys.app, generate a random DiceKey (a throwaway one, never your real DiceKey),
and scan the picture of its 25 dice from another screen.

`scripts/testflight.sh` builds and uploads to TestFlight; see the architecture document.
